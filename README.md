## 🚀 Featured Project: Malicious IP Sorter

**The Problem:** Manually sorting through thousands of threat feed IPs takes too long. 

**What I Built:** A Python script that ingests raw IP lists, checks them against reputation APIs, and outputs a prioritized JSON file showing only the top 5% of critical threats (C2 / Malware traffic).

**The Result:** Cuts manual triage time from 45 minutes to under 3 seconds.
